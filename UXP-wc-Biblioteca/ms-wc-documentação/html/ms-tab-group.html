MS Tab Group

Um componente de abas personalizável que permite organizar conteúdo em diferentes painéis navegáveis em Plugins UXP - Adobe Photoshop.

Index.html


<ms-tab-group>
    <ms-tab titulo="Aba 1">
    Conteúdo da primeira aba
    </ms-tab>
    <ms-tab titulo="Aba 2">
    Conteúdo da segunda aba
    </ms-tab>
    <ms-tab titulo="Aba 3" active><!--deifine a aba ativa -->
    Conteúdo da terceira aba
    </ms-tab>
</ms-tab-group>

Componentes

Componente Descrição
<ms-tab-group> Contenedor principal que gerencia as abas
<ms-tab> Representa uma aba individual e seu conteúdo

Atributos

ms-tab-group

Atributo Tipo Descrição
active Number Índice da aba que deve estar ativa (base 0)

ms-tab

Atributo Tipo Descrição
titulo String Texto a ser exibido no botão da aba
active Boolean Define se a aba deve estar ativa inicialmente

Eventos

Evento Detalhe Descrição
tab-change { index: number, text: string } Disparado quando uma aba é selecionada. Retorna o índice e o texto da aba ativa

Métodos

Método Descrição
activateTab(index) Ativa a aba no índice especificado
getActiveTabText() Retorna o texto da aba atualmente ativa

Integração com JavaScript


// Obtendo referência ao componente
const tabGroup = document.querySelector('ms-tab-group');
// Escutando mudanças de aba
tabGroup.addEventListener('tab-change', (event) => {
    console.log('Aba ativa:', event.detail.index);
    console.log('Texto da aba:', event.detail.text);
});
// Ativando uma aba específica
tabGroup.activateTab(1); // Ativa a segunda aba
// Obtendo o texto da aba ativa
const activeTabText = tabGroup.getActiveTabText();

Exemplos de Uso

Abas com Conteúdo Dinâmico


<ms-tab-group>
    <ms-tab titulo="Configurações">
        <div class="settings-panel">
            <!-- Conteúdo de configurações -->
        </div>
    </ms-tab>
    <ms-tab titulo="Dados">
        <div class="data-grid">
            <!-- Grid de dados -->
        </div>
    </ms-tab>
</ms-tab-group>

Abas com Aba Inicial Específica

<ms-tab-group active="1">
    <ms-tab titulo="Geral">
        Configurações gerais
    </ms-tab>
    <ms-tab titulo="Avançado">
        Configurações avançadas
    </ms-tab>
</ms-tab-group>

Estilização

O componente utiliza variáveis CSS personalizadas para estilização:

  • --psfx-ui-borda-forte-color: Cor da borda do container
  • --psfx-ui-bg-color: Cor de fundo do container
  • --psfx-box-shadow: Sombra do container
  • --psfx-bg-detalhes-color: Cor de fundo dos botões
  • --psfx-texto-color-2: Cor do texto dos botões
  • --psfx-texto-color: Cor do texto no hover
  • --psfx-botao-naveg-Abas: Cor de fundo da aba ativa

Nota!

  • O componente suporta um número ilimitado de abas
  • As abas são responsivas e se ajustam ao espaço disponível
  • O conteúdo das abas pode incluir qualquer elemento HTML
  • A navegação pode ser feita via clique ou programaticamente
