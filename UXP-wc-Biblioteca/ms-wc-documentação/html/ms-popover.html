MSPopover

O componente MSPopover é um popover customizado, encapsulado como um Web Component, que permite exibir conteúdos adicionais de forma flutuante, posicionados em relação a um elemento disparador. Ele é projetado com suporte a posicionamento flexível, estilo customizável via CSS, e comportamentos como habilitar/desabilitar e exibir/esconder dinamicamente.

Como Funciona

O MSPopover funciona como um elemento HTML customizado que exibe um conteúdo flutuante quando disparado por um elemento configurado via atributo trigger-for. Ele ajusta automaticamente sua posição com base no elemento disparador e pode ser controlado por atributos como position, seta e disabled.

Atributos

ms-popover

Atributo Descrição Padrão Exemplo
size Define a largura do popover. Não definido <ms-popover size="200px"></ms-popover>
seta Controla a exibição de uma seta indicadora. false <ms-popover seta="true"></ms-popover>
position Determina a posição do popover em relação ao elemento disparador. center <ms-popover position="top"></ms-popover>
disabled Desabilita o popover e seu disparador. false <ms-popover disabled></ms-popover>

index.html

Conteúdo com tamanho definido


<ms-popover size="300px" trigger-for="btn-size">
    <div>conteudo popover</div>
</ms-popover>
<button id="btn-size">Abrir Popover (size)</button>

Popover com seta de posicionamento


<ms-popover seta="true" position="top" trigger-for="btn-seta">
    <div>conteudo popover</div>
</ms-popover>
<button id="btn-seta">Abrir Popover (seta)</button>

Popover posicionado na direção atribuida "abaixo"


<ms-popover position="bottom" trigger-for="btn-position">
    <div>conteudo popover</div>
</ms-popover>
<button id="btn-position">Abrir Popover (position)</button>

Desativando o botão disparador do evento


<ms-popover disabled trigger-for="btn-disabled">
    <div>conteudo popover</div>
</ms-popover>
<button id="btn-disabled">Popover Desativado</button>

Fechando o popover apartir de elementos filhos


<button id="arrowBtn">Abrir com Seta</button>
<ms-popover trigger-for="arrowBtn" position="top" seta="true">
    <div>
        <h3>Título do Popover</h3>
        <p>Algum conteúdo aqui...</p>
        < !-- Botão que fecha o popover -->
        <button data-popover-close>Fechar</button>
        < !--Qualquer elemento que deve fechar o popover -->
        <div data-popover-close>Clique aqui para fechar</div>
    </div>
</ms-popover>

Integração com index.js


const popover = document.querySelector('ms-popover');

DEFINIR O TAMANHO COM BASE NA LARGURA


popover.setAttribute('size', "150px");

DEFINE A POSIÇÃO DE EXIBIÇÃO DO POPOVER


 popover.setAttribute('position', "right");

OPÇÃO PARA INCLUIR SETA DE DIRECIONAMENTO


popover.setAttribute('seta', "true");

DESABILITANDO E HABILITANDO


popover.disable(); //Desabilitar
popover.enable(); //Habilitar

Nota!

  • Relacionamento com o disparador (trigger-for):
    Certifique-se de que o atributo trigger-for contenha o ID correto de um elemento existente no documento. Caso contrário, o popover não será ativado e um erro será exibido no console
  • Atributo position:
    As opções válidas para o atributo position são: top, bottom, left, right e center. Se nenhuma posição for definida ou se um valor inválido for usado, o popover será posicionado no centro do elemento disparador.
  • Estilos Personalizados:
    Variáveis CSS como --psfx-bg-detalhes-color e --psfx-texto-disbled-color são utilizadas para estilizar o componente. Certifique-se de defini-las em seu CSS global para evitar que o popover apareça sem estilos.
  • Atributo disabled:
    Quando o popover está desativado (com o atributo disabled), o disparador associado também será desativado automaticamente. Caso precise habilitar novamente, remova o atributo disabled tanto do popover quanto do botão disparador.
  • Responsividade e Ajustes na Tela:
    O popover realiza ajustes automáticos para não ultrapassar os limites da janela. No entanto, em telas pequenas, certifique-se de que o conteúdo seja compacto o suficiente para caber no espaço disponível.
