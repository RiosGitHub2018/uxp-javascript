MS-icon

ms-icon é um componente web personalizado para renderizar ícones SVG com atributos personalizáveis, como tamanho, cor e efeitos de hover. Ele suporta carregamento dinâmico de ícones e fornece um ícone de erro como fallback quando o SVG especificado não pode ser carregado.

Como Funciona

O componente busca arquivos SVG dinamicamente com base no atributoicon. Aplica estilos como tamanho, cor e cor de hover usando variáveis CSS ou atributos. Gerencia estados como disabled, renderizando um estilo desativado quando aplicável. Se um ícone não puder ser carregado, um ícone de erro padrão é exibido.

index.html


Exemplo Básico
<ms-icon icon="home" size="40px" color="black"></ms-icon>
Com Efeito de Hover
<ms-icon icon="settings" size="50px" color="gray" hover-color="blue"></ms-icon>
Ícone Desativado
<ms-icon icon="delete" disabled></ms-icon>

Atributos

ms-icon

Atributo Descrição Padrão Exemplo
icon Especifica o nome do ícone SVG a ser carregado Sem atribuir <ms-icon icon="home"></ms-icon>
size Especifica o tamanho do ícone 40px <ms-icon size="50px"></msicon>
color Define a cor do ícone var(--psfx-texto-color) <ms-icon color="blue"></msicon>
hover-color Define a cor do ícone quando o cursor está sobre ele var(--psfx-texto-color) <ms-icon hover-color="red"></ms-icon>
disabled Desativa a interação com o ícone var(--psfx-ui-slider-circulardisabled-color) < ms-icon disabled>< /msicon>

Integração com index.js

Você pode manipular o componentems-icon dinamicamente usando JavaScript: Habilitando/Desabilitando Ícones


const iconElement = document.querySelector('ms-icon');
iconElement.disable(); // Desativar o ícone
iconElement.enable(); // // Habilitar o ícone

Ou:


const iconElement = document.querySelector('ms-icon');
iconElement.setAttribute('disabled', ''); // Desativar o ícone
iconElement.removeAttribute('disabled'); // Habilitar o ícone

Alterando Atributos Dinamicamente


const iconElement = document.querySelector('ms-icon');
iconElement.setAttribute('icon', 'user'); // Alterar o ícone
iconElement.setAttribute('color', 'green'); // Alterar a cor

Ouvinte de eventos


const iconElement = document.querySelector('ms-icon');
iconElement.addEventListener('click', () => {
    console.log("Aqui o evento de click do iconElement!")
 })

Tratamento de Erros

Se o atributo icon especificado não apontar para um arquivo SVG válido, um ícone de erro será renderizado automaticamente.


<ms-icon icon="nonexistent-icon"></ms-icon>

Isso renderizará um ícone de erro padrão com um círculo e um ponto de exclamação.

Notas

• Certifique-se de que o diretório icons seja acessível a partir da raiz da sua aplicação.
• Use variáveis CSS para manter uma temática consistente em sua aplicação.
• O componente é compatível e foi testado em plugins uxp que suportam Custom Elements em Adobe Photoshop.

Conclusão

O componente web ms-icon fornece uma maneira leve e flexível de usar ícones SVG escaláveis em seus plugins uxp. Com recursos como carregamento dinâmico de SVG, estilos personalizáveis e tratamento de erros, ele simplifica o gerenciamento de ícones e melhora a consistência da interface do usuário.
