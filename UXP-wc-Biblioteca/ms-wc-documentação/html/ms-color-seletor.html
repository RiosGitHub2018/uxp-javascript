MSColorSelector

O MSColorSelector é um web componente customizado que implementa um seletor de cores interativo e personalizável, permitindo a escolha de tonalidades diretamente por meio de um controle visual. Ele suporta atributos como tamanho, cor inicial e posição, além de disparar eventos de mudança de cor para maior integração com outros sistemas.

Como Funciona

O componente MSColorSelector funciona como um elemento HTML customizado que exibe um seletor de cores ao ser acionado. Ele utiliza dois canvas para representar a escala de matiz e o controle de saturação/valor, atualizando a cor selecionada em tempo real.

Atributos

MSColorSelector

Atributo Descrição Padrão Exemplo
size Define o tamanho do seletor 50 <ms-color-seletor size="50"></ms-color-seletor>
initial-color Especifica a cor inicial exibida no seletor, em formato hexadecimal. #FFFFFF <ms-color-seletor initial-color="#FF5733"></ms-color-seletor>
position Determina a posição do seletor em relação ao elemento que o aciona. default <ms-color-seletor position="bottom"></ms-color-seletor>
trigger-for ID do elemento que aciona a abertura do seletor de cores ao ser clicado. null <ms-color-seletor trigger-for="btnOpen"></ms-color-seletor>
disabled Desabilita a interação com o seletor de cores. Vazio <ms-color-seletor disabled="true"></ms-color-seletor>

function cssColorHex(corCSSvar){
    const getColorValue = (cssVar) => {
        const element = document.createElement('div');
        element.style.color = cssVar;
        document.body.appendChild(element);
        const color = window.getComputedStyle(element).color;
        document.body.removeChild(element);
        return color;
        }
        // Uso:
        const cssColor = getColorValue(corCSSvar);
        return cssColor;
}

    Nota!

    • Tamanho do seletor (size):
      Certifique-se de usar valores em porcentagem (entre 40 a 100). Valores inválidos podem causar distorções no seletor.
    • Cor inicial (initial-color):
      A cor inicial deve ser fornecida no formato hexadecimal válido, como #FFFFFF. Fornecer um valor inválido pode causar um comportamento inesperado ou erro.
    • Atributo de posição (position):
      Use apenas valores válidos como top, bottom, left, right ou center. Qualquer outro valor será tratado como default, posicionando o seletor abaixo do elemento acionador.
    • Elemento acionador (trigger-for):
      O elemento acionador precisa ter um ID válido que coincida com o valor definido no atributo trigger-for. Sem isso, o seletor não será exibido.
    • Estado desabilitado (disabled):
      Quando o atributo disabled for aplicado, o seletor ficará completamente desabilitado, incluindo a interação com o botão acionador. Remova o atributo para reativar o componente.
    • Compatibilidade com estilos personalizados:
      O seletor utiliza variáveis CSS como --psfx-ui-bg-color e --psfx-box-shadow. Certifique-se de definir essas variáveis no seu arquivo de estilos para garantir uma aparência consistente.
