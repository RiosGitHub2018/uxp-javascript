MSDropdowlist

O componente MSDropdownlist é um elemento customizado que funciona como um menu suspenso interativo. Ele permite selecionar opções de uma lista e suporta submenus dinâmicos, ícones e personalizações visuais como cor de texto e ícones de opções.

Como Funciona

O componente PSDropdownlist é um menu suspenso personalizado que exibe uma lista de opções, com suporte para ícones e submenus. Ele permite selecionar itens, interagir com subitens e fornece eventos para manipular a seleção.

Atributos

ms-dropdowlist

Atributo Descrição Padrão Exemplo
data-selected-index Define o índice da opção selecionada no dropdown. 0 <ms-dropdownlist data-selected-index="2"></ms-dropdownlist>
disabled desabilita o ms-dropdowlist Vazio <ms-dropdownlist disabled></ms-dropdownlist>

ms-item

Atributo Descrição Padrão Exemplo
icon Define o ícone a ser exibido ao lado do item. Vazio <ms-item icon="icon.005">Item com ícone</ms-item>
subitem Define um subitem ou uma opção adicional dentro do item. Vazio <ms-item subitem='["Banner", "Chaxis"]'>Item com subitem</ms-item>
color Define a cor do ícone. Vazio <ms-item color="red">Item com cor</ms-item>

ms-divider

Padrão Descrição Exemplo
<ms-divider> serve para criar uma linha divisória entre itens da lista. <ms-item >item 01</ms-item>
<ms-divider></ms-divider>
<ms-item >item 02</ms-item>
<ms-item >item 03</ms-item>

Integração com index.js


const dropdown = document.querySelector('ms-dropdownlist');

1: Carregamento dinâmico com array de string


const array = ["João", "Maria", "Pedro", "Catia", "Raimundo", "Mauricio"];
setTimeout(() => {
    array.forEach(item => {dropdown.addOption(item); });
    dropdown.selectedIndex = 3;
}, 90);

Ouvintes de eventos

• Itens com carregamento padrão inline com suporte a subitens


setTimeout(() => {
  dropdown.addEventListener('optionSelected', (event) => {
      const { value, subitem, subitemIndex, } = event.detail;
      if (subitem) {
        console.log(`Selecionado: ${value} - Subitem: ${subitem} (Índice do Subitem: ${subitemIndex})`);
      } else {
        console.log(document.querySelectorAll('ps-item[subitem]'));
      }
  });
}, 90);

• Itens com carregamento dinâmico apartir de "array de string"


setTimeout(() => {
  dropdown.addEventListener('optionSelected', (event) => {
    const { value, originalObject, selectedIndex } = event.detail;
    console.log(`Nome: ${value}\n${selectedIndex}\n${originalObject}`);
  });
}, 90);

• Itens com carregamento dinâmico apartir de "array de objetos"


setTimeout(() => {
  dropdown.addEventListener('optionSelected', (event) => {
    const { value, originalObject } = event.detail;
    if (originalObject) {
      console.log(`Nome: ${value}`);
      console.log(`Idade: ${originalObject.idade}`);
      console.log(`Sexo: ${originalObject.sexo}`);
      console.log(`Icone: ${originalObject.icon}`);
      console.log(`Color: ${originalObject.color}`);
    }
  });
}, 90);

Nota!

1. Uso Semântico e Estrutural

  • Use tags como <ms-item>, <ms-divider>, e <ms-dropdownlist> de forma consistente com seus propósitos.
  • Exemplo: Use <ms-divider> para separar visualmente itens, mas não para criar espaços sem significado semântico.

2. Compatibilidade com plugins uxp Adobe Photoshop

  • Verifique se o plugin suporta Web Components ou inclua um polyfill necessário para tags customizadas.

3. Atributos Customizados

  • Use atributos como icon, subitem, e color de forma consistente para evitar comportamentos inesperados.
  • Certifique-se de que os valores atribuídos aos atributos são aceitos pela implementação da tag.
  • Exemplo: 
    <ms-item icon="home" color="blue">Início</ms-item>

4. Hierarquia e Organização

  • Certifique-se de que elementos como <ms-item> e <ms-divider> estejam dentro de contêineres apropriados, como <ms-dropdownlist>.

5. Manutenção e Legibilidade

  • Comente e documente o uso das tags no código para facilitar a manutenção por outros desenvolvedores.
  • Exemplo: 
    <!-- Item principal com ícone e cor personalizada -->
<ms-item icon="home" color="blue">Início</ms-item>
