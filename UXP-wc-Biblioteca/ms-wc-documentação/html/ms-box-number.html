MSBoxNumber

O componente MSBoxNumber é um Web Component customizado que exibe e gerencia um campo numérico estilizado com suporte a personalização de tamanho, sufixos de valor e controle interativo para incrementar ou decrementar valores. Ele utiliza Shadow DOM para encapsular o estilo e comportamentos, garantindo modularidade e reutilização.

Como Funciona

O componente MSBoxNumber funciona como um campo numérico interativo que permite definir e alterar valores usando botões de incremento/decremento ou entrada direta. Ele suporta personalizações, como tamanho ajustável, sufixos de valor e estados habilitado/desabilitado.

Atributos

MSBoxNumber

Atributo Descrição Padrão Exemplo
size Define a largura do componente: unidades CSS (px, em, rem, %). 100px <ms-box-number size="200px"></ms-box-number>
data-label Define o texto exibido como rótulo do componente. Vazio <ms-box-number data-label="Largura"></ms-box-number>
value Define o valor inicial do campo numérico. 0 <ms-box-number value="10"></ms-box-number>
value-suffix Adiciona um sufixo ao valor exibido, como uma unidade de medida. Vazio <ms-box-number value-suffix="cm"></ms-box-number>
disabled Desabilita o componente, tornando-o não interativo. Habilitado <ms-box-number disabled></ms-box-number>

index.html


<!-- Definindo largura do componente -->
<ms-box-number size="150px"></ms-box-number>
<!-- Adicionando um rótulo -->
<ms-box-number data-label="Largura"></ms-box-number>
<!-- Definindo um valor inicial -->
<ms-box-number value="25"></ms-box-number>
<!-- Adicionando um sufixo ao valor -->
<ms-box-number value-suffix="cm"></ms-box-number>
<!-- Componente desabilitado -->
<ms-box-number disabled></ms-box-number>

Integração com index.js


const numberBox = document.querySelector(ms-box-number);

Desabilitando e habilitando


setTimeout(() => {
    numberBox.disable(); // DESABILITA
    numberBox.enable();  // HABILITA
}, 30)

Ouvinte de eventos


numberBox.addEventListener('change', () => {
    console.log(`Valor atual: ${numberBox.value}`);
});

Manipulação Dinâmica de Atributos com setTimeout


setTimeout(() => { 
    numberBox.setAttribute('size', "100px");
    numberBox.setAttribute('value', "80.5");
    numberBox.setAttribute('value-suffix', "cm");
    numberBox.setAttribute("data-label", "Size");
}, 90);

Nota!

  • 1. Sincronização de Alterações Dinâmicas:

    Ao usar métodos como setTimeout para manipular os atributos do componente, certifique-se de que o componente já está conectado ao DOM antes de modificar seus atributos. Alterações em componentes não montados podem não ser aplicadas corretamente.

  • 2. Compatibilidade com Atributos Dinâmicos:

    Certifique-se de que os valores passados aos atributos são válidos para cada tipo de dado esperado:
    • size: Aceita valores numéricos ou com unidades CSS válidas.
    • value: Deve ser um número válido ou convertível para número.
    • value-suffix e data-label: Aceitam texto, mas evite caracteres que possam causar problemas de renderização.

  • 3. Desempenho e Alterações Simultâneas:

    Alterações simultâneas em atributos podem causar eventos repetidos de atualização visual ou funcional. Para otimizar o desempenho, considere agrupar alterações relacionadas dentro de uma única operação.

  • 4. Acessibilidade:

    Ao definir atributos dinamicamente, como data-label, lembre-se de que eles podem impactar a acessibilidade do componente. Certifique-se de que os rótulos e atributos estão claros para ferramentas assistivas.
